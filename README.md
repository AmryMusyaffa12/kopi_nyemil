# Kopi dan Nyemil ☕🥐

Aplikasi mobile Android sederhana untuk pemesanan kopi dan makanan ringan (cemilan) yang dikembangkan sebagai penugasan mata kuliah Pemrograman Mobile menggunakan **Kotlin** dan **XML**.

## 📱 Fitur Aplikasi
Aplikasi ini dirancang berdasarkan *wireframe* dengan alur 8 layar utama:
1. **Splash / Welcome Screen**: Halaman pembuka dengan logo aplikasi.
2. **Sign Up & Login**: Halaman autentikasi pengguna.
3. **Register**: Halaman pendaftaran akun baru.
4. **Home**: Menampilkan sapaan nama pengguna, profil, serta daftar menu (minimal 5 item menu makanan dan minuman).
5. **Profile**: Halaman untuk melihat dan memperbarui informasi nama pengguna yang tersimpan secara dinamis ke halaman Home menggunakan Intent.
6. **Order / Alamat Pengiriman**: Halaman input detail pesanan dan alamat pengiriman.
7. **Confirmation**: Halaman konfirmasi pesanan berhasil.

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman**: Kotlin
- **UI Framework**: Android XML (LinearLayout, FrameLayout, ScrollView)
- **Komponen Utama**: Activity, Intent, ImageView, Button, TextView, EditText.
- **Manajemen Data**: Menggunakan data statis (*dummy data*) sesuai ketentuan tanpa database eksternal.

## 🚀 Cara Menjalankan Aplikasi
1. Clone atau download repository ini ke komputer Anda.
2. Buka aplikasi **Android Studio**.
3. Pilih **Open an Existing Project** dan arahkan ke folder project ini.
4. Tunggu proses *Gradle Sync* sampai selesai.
5. Sambungkan perangkat Android fisik (dengan USB Debugging aktif) atau jalankan melalui Android Emulator.
6. Klik tombol **Run (Shift + F10)** untuk menginstal dan menjalankan aplikasi.
